## Intro

The Hyperbridge Protocol project is broken up into related types:

* Token - in the `packages/token` dir
* Funding - in the `packages/funding` dir
* Marketplace - in the `packages/marketplace` dir
* Crowdsale - in the `packages/crowdsale` dir
